# Who's Buying Coffee?

커피를 살 사람을 가볍게 정하는 브라우저 게임 모음입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## Cloudflare Pages 배포

- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- 권장 Node.js 버전: `22`

GitHub 저장소를 Cloudflare Pages에 연결하면 `main` 브랜치가 갱신될 때 자동으로 다시 배포할 수 있습니다.
